# SmartSpend - Personal Finance Dashboard

A personal finance dashboard built with React.js and Vite.

## Features

- Dashboard overview (balance, income, expenses, savings, budget)
- Add, edit, delete transactions with search, filter, and sort
- Budget tracker with progress bar and status
- Analytics with bar, pie, and line charts (Recharts)
- Spending insights and statistics
- Recent activity feed
- Quick add buttons for common expenses
- CSV export
- Dark/Light mode with localStorage persistence
- Fully responsive design
- Data persists across browser refreshes via localStorage

## Setup

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Tech Stack

- React.js (Vite)
- JavaScript
- CSS
- Recharts
- React Icons
- localStorage
